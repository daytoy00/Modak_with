MODAK b11 - GitHub Pages 배포

1. 이 폴더의 파일 전체를 GitHub 저장소 루트에 업로드하여 교체하세요.
2. GitHub Pages가 반영된 뒤 새로고침하세요. 설치된 PWA는 캐시 갱신이 필요할 수 있습니다.
3. PC 두 대 또는 서로 다른 네트워크에서 화면공유 / 마이크 / 채팅 / 재접속을 검증하세요.
4. 중요: GitHub Pages + PeerJS 공개 서버만으로는 방장 권한과 최대 인원 제한을 보안 수준으로 강제할 수 없습니다. UI/Peer 메시지 기준 제한입니다. 강력한 방 제어와 TURN 서버 사용에는 별도의 백엔드가 필요합니다.
5. 권한/네트워크 환경에 따라 WebRTC 연결을 보장할 수 없습니다. STUN만 설정되어 있으므로 일부 NAT 환경에서 TURN 서비스 필요.

포함: 메뉴 3분리, 독립 팝오버, 테마, 채팅/프로필 투명도, 알림음 분리, 개별 음성 음량, 상태 아이콘, PiP, 원본 불꽃 파비콘, 입장 안내 제거.
